<h1>Trying out pull request!</h1>

1. `Fork` the repository
2. Clone the repository

```
git clone https://github.com/Seann2003/hackthletes-github-workshop.git
```

3. Commit and push your changes
4. Go back to the forked repository page
5. Click on `Contribute`, and click `Open Pull Request`
6. Specify your name and TP number the title, click``Create pull request``
